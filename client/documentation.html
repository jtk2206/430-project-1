Pokemon API Documentation

/getPokemonNames (GET, HEAD)

Query Params:

None

Returns:

JSON array of pokemon names, formatted [string]

Examples:

Request: /getPokemonNames

Result: {"names":["Bulbasaur","Ivysaur","Venusaur","Charmander"...

/getPokemon (GET, HEAD)

Query Params:

Name(Optional): Name of the pokemon to filter by

Type(Optional): Type of pokemon to filter by, only supports one type

Weakness(Optional): Weakness of pokemon to filter by, only supports one weakness

Returns:

JSON array of pokemon objects

Format: {"returnPokemon":[{"id":1,"num":"001","name":"Bulbasaur","img":"http:/...

Examples:

Request: /getPokemon?type=Fire

Result: {"returnPokemon":[{"id":4,"num":"004","name":"Charmander","img":...

/getPokemonByName (GET, HEAD)

Query Params:

Name(Required): Name of the pokemon you are looking for

Returns:

JSON pokemon object

Format: {"returnPokemon":[{"id":1,"num":"001","name":"Bulbasaur","img"...

Examples:

Request: /getPokemonByName

Result: 400 Error

Request: /getPokemonByName?name=idontexist

Result: 404 Error

Request: /getPokemonByName?name=Pikachu

Result: {"returnPokemon":[{"id":25,"num":"025","name":"Pikachu","img"...

/addPokemon (POST)

Supported Body Formats

application/json, application/x-www-form-urlencoded

Body Params:

Name(Required): Name of the pokemon

Types(Required): Type(s) of the pokemon

Weaknesses(Optional): Weakness(es) of the pokemon

Returns:

The new JSON pokemon object

Format: {"newPokemon":{"name":"Test","type":["testType"]}}

Examples:

Request: /addPokemon

Body: {"name":"Test","type":'testType1,testType2',weaknesses:'testWeakness'"}}

Result: {"newPokemon":{"name":"Test","type":["testType,testType2"],"weaknesses":["testWeakness"]}}

Request: /addPokemon

Body: {"name":"Test2",weaknesses:'testWeakness'"}}

Result: 400 Error

/addGeneration (POST)

Supported Body Formats

application/json, application/x-www-form-urlencoded

Body Params:

Name(Required): Name of the pokemon

Generation(Required): Generation of the pokemon

Returns:

No Content

Examples:

Request: /addGeneration

Body: {"name":"Test","generation":'testGen'"}}

Result: Updated, 204

Request: /addGeneration

Body: {"name":"Test2""}}

Request: /addGeneration
